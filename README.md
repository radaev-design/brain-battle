# BRAIN BATTLE
Telegram Mini App — соревновательная викторина. Сейчас: Phase 1 (дизайн-система и HOME).

## Запуск
```
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка сборки
```
## Публикация
GitHub → Settings → Pages → Source: **GitHub Actions**. Пуш в `main` деплоит сайт автоматически.
